# SpineDx-Tx v28.2 Smart Rapid Review

## Clinical corrections
- Rapid motor entry begins with whether a reproducible focal deficit is present. Side, root, grade, and reliability appear only when abnormal.
- Rapid imaging begins with whether a potentially relevant compressive finding is present. Level, zone, and severity appear only when present.
- Severity `none` is not available for a declared candidate abnormality.
- No invasive pathway is displayed plainly rather than as `none without a level`.
- Nonoperative text is conditional on treatments already attempted and injection response.
- Missing-data conclusions are consensus framework outputs and do not receive inappropriate disease-treatment citations.

## Boundary
This remains a deterministic research prototype. It organizes entered findings; it does not diagnose, select treatment, or replace direct examination and image review.
