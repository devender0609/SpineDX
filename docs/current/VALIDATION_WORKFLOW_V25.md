# Validation Workflow

The validation dataset must preserve four distinct concepts:

1. Independent clinician judgment before app exposure.
2. App output from a frozen version.
3. Multidisciplinary adjudicated reference standard.
4. Actual treatment and observed outcomes.

These must not be collapsed into one label. The app should not learn during the locked validation phase. Model development and validation cohorts must be separated by patient and preferably by time or site.
