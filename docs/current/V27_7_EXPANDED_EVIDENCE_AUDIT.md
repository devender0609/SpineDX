# v27.7 Expanded Evidence Audit

This release expands the curated evidence library and technical registry. It does not change clinical decision rules. Added domains include asymptomatic imaging prevalence, examination accuracy, SPORT long-term outcomes, foraminal grading, pseudarthrosis risk, and frailty. The library remains curated rather than exhaustive until a formal systematic search, risk-of-bias appraisal, and multidisciplinary adjudication are completed.
