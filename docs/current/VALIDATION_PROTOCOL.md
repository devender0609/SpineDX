# Validation workflow — protocol skeleton

1. Record eligibility and all required safety findings.
2. First reviewer records syndrome, side, root, level, zone, urgency, testing, specialist-review support, decompression target, fusion rationale, confidence, and rationale before viewing app output.
3. Second reviewer records the same variables independently.
4. Adjudicators review clinical data and imaging without app output, actual treatment, or outcomes.
5. Record consensus method and disagreement reason; indeterminate is permitted.
6. Lock the application and ruleset during validation.
7. Keep actual treatment and outcomes separate from appropriateness labels.
8. Prespecify primary endpoints, error severity, missing-data handling, subgroup analyses, and acceptance thresholds before enrollment.
