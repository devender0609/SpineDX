# SpineDx-Tx v28.0 Physician Value Workflow

## Purpose
This release is designed around three adoption questions:

1. Does the workflow reduce duplicate physician documentation?
2. Does it surface clinically important inconsistencies before synthesis?
3. Does it standardize communication across clinicians?

## Rapid review
Rapid review is the default. It keeps decision-critical history, safety, focused examination, imaging, and plan reconciliation visible while hiding optional outcome measures and expanded details. Comprehensive review remains available for complex cases and research-quality documentation.

## Attention check
The review step summarizes blocking errors, important warnings, and advisories. The synthesis preserves unresolved warnings generated from the frozen case snapshot and displays the highest-priority items in a Do not miss strip.

## Standardized handoff
The synthesis provides a four-domain handoff: clinical problem, candidate localization, immediate priority, and recommended action. The existing copy-summary and print functions remain available.

## Boundaries
This release does not claim EMR integration or autonomous documentation. It reduces on-screen burden through progressive disclosure and standardizes the final synthesis. Secure chart prepopulation and write-back require institutional integration and governance.
