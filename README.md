# SpineDx-Tx AI v0.6

Research prototype for adult lumbar degenerative presentations. This version adds explicit surgical decision context, procedure-specific possibilities, operative prerequisites, risks, and safer handling of progressive weakness. It is not clinically validated and must not be used for autonomous diagnosis, ordering, authorization, or surgical selection.

## Run
npm install
npm run build
npm run dev

## Governance
Every rule must have a versioned evidence source, exception set, potential-harm analysis, multidisciplinary approval, retrospective validation, silent prospective validation, and post-deployment monitoring before clinical use.
